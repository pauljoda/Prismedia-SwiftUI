# iPhone Duo reference

The `iphone-duo-*` skills in `../skills/` and the sheets in this folder are
copied unmodified from
[mirzaaghazadeh/iphone-duo-skills](https://github.com/mirzaaghazadeh/iphone-duo-skills)
at commit `f62a73fe9bf7cd85056e25f7f565227bf4fda364` (30 September 2026),
under the MIT license in `LICENSE-iphone-duo-skills`. The skills link here as
`../../reference/…`, so keep this folder beside `skills/`.

Installed: readiness, adaptive-layout, vertical-bars, hinge-and-scenes,
dual-pane-patterns and design-review. Not installed: camera, games, flutter,
react-native and capacitor, so their cross-links don't resolve.

To update, copy the same files from a newer checkout. Prismedia's own rules,
learned while adapting the app, live in `../skills/prismedia-adaptive-layout/`,
not in these files.
